# UAgent 源码位置与职责

## 主工程

`D:\uagent` 是新版本唯一主工程。所有新功能、测试和文档都放在这里。

| 目录 | 职责 |
|---|---|
| `core` | React/Figma Make 依赖图、资源图、组件/状态/事件/动画中间模型 |
| `adapters` | LVGL/UIBuilder 控件适配器和 `custom.c` 逻辑生成 |
| `frontend` | 现代化 Agent 工作台、源码/视频/预览/日志界面 |
| `tests` | 跨项目回归测试和 golden 结果 |
| `docs` | 架构、支持矩阵、降级规则和测试报告 |
| `workspaces` | 每次导入的临时副本和生成工程，不提交到源码库 |

## 旧工程

`D:\aiassit` 及其 exe 是旧版本，仅用于对照和迁移验证。新功能不得继续堆入旧版特例。

## 处理原则

源码解析必须递归完成整个依赖图。每个资源、组件、状态、事件和动画都必须在中间模型中有记录，并标记 `native`、`partial` 或 `fallback`。
